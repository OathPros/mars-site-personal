# Process model

The canonical process is a six-stage, revisitable flow: **Discover, Shape, Prototype, Review, Production, Operate**. It applies to all York-developed AI solutions. MARS is one platform path.

The website renders this as an interactive HTML process rather than a static diagram. Thirteen primary points form the main path. Early AIDE consultation, specialist consultation and IPPM are visible optional or conditional branches. Selecting a point highlights its position, opens detailed actions and links to the relevant working tool; stage filters and a stacked mobile presentation preserve readability.

1. Define the need and search the AI Solutions Inventory and York services. Reuse or join work where appropriate; otherwise create or update a lightweight record.
2. Select a path, complete platform prerequisites and use the Ideation Guide where useful. Direct IPPM intake remains available.
3. Prototype under **Interim guidance** and reassess changes to scope, data, users, integrations, costs, risks or production intent.
4. Consult the AIDE Committee when guidance or review is required. AIDE documents recommendations; it does not make approval decisions.
5. Complete conditional specialist reviews and Change Management review before production. Confirm an accepted named operational owner and support model.
6. If approved through the applicable process, deploy; then operate, support, review, change or retire the solution.

AIDE may recommend IPPM and IPPM may refer AI work to AIDE. Neither is an exclusive gateway to the other. ITAC is not part of the standard process.
