# Routing rules

The pure `getNextStep` function evaluates the current stage and relevant signals in priority order.

1. Production or institutional intent → required Change Management preparation guidance.
2. Sensitive data, decisions affecting people, integrations or privileged access, work outside interim guidance, or a major live-solution change → required AIDE consultation guidance and possible specialist referral.
3. Material resource need → optional resourcing route with both direct IPPM access and AIDE advice. This never claims an initiative is automatically created.
4. Inventory search → optional search and reuse route.
5. Closure → required retirement planning guidance.
6. Unclear owner/support → required ownership clarification.
7. Otherwise → continue under interim prototype guidance; AIDE remains optional and available early.

Every result includes a recommendation, rationale, required/optional label, preparation list and direct route. The UI lets users revise answers.
